Problem 1: Gauss–Jacobi Iterative Method

Linear Systems
System of Equations:
(1) 9x - y + 2z = 18
(2) 2x + 8y - z = -5
(3) x - 2y + 10z = 21
Initial guess: x⁽⁰⁾ = 0, y⁽⁰⁾ = 0, z⁽⁰⁾ = 0.

Step-by-Step Derivation

1. Strict Diagonal Dominance Check:

  • Row 1: |9| = 9 > |-1| + |2| = 3 (Valid)
  • Row 2: |8| = 8 > |2| + |-1| = 3 (Valid)
  • Row 3: |10| = 10 > |1| + |-2| = 3 (Valid)

2. Iteration Recurrence Relations:

x⁽ᵏ⁺¹⁾ = (18 + y⁽ᵏ⁾ - 2z⁽ᵏ⁾) / 9
y⁽ᵏ⁺¹⁾ = (-5 - 2x⁽ᵏ⁾ + z⁽ᵏ⁾) / 8
z⁽ᵏ⁺¹⁾ = (21 - x⁽ᵏ⁾ + 2y⁽ᵏ⁾) / 10

Python Program (problem_1_gauss_jacobi.py)

def gauss_jacobi(tol=1e-4, max_iter=50):
    x, y, z = 0.0, 0.0, 0.0
    for k in range(1, max_iter + 1):
        x_new = (18.0 + y - 2.0 * z) / 9.0
        y_new = (-5.0 - 2.0 * x + z) / 8.0
        z_new = (21.0 - x + 2.0 * y) / 10.0
        if max(abs(x_new - x), abs(y_new - y), abs(z_new - z)) < tol:
            return k, x_new, y_new, z_new
        x, y, z = x_new, y_new, z_new

Python Program (problem_2_gauss_seidel.py)

def gauss_seidel(tol=1e-4, max_iter=50):
    x, y, z = 0.0, 0.0, 0.0
    for k in range(1, max_iter + 1):
        x_old, y_old, z_old = x, y, z
        x = (10.0 - y + z) / 5.0
        y = (-2.0 + x - 2.0 * z) / 6.0
        z = (9.0 - 2.0 * x + y) / 7.0
        if max(abs(x - x_old), abs(y - y_old), abs(z - z_old)) < tol:
            return k, x, y, z

Problem 3: Euler’s Method for Initial Value Problems

1st Order ODE
Problem Specification:
dy/dx = x + y², y(0) = 1, step size h = 0.1
Target: Estimate y(0.1), y(0.2), and y(0.3).

Recurrence Formula: y_(n+1) = y_n + h · (x_n + y_n²)

Step 1: x=0.0 → 0.1
f(0, 1) = 0 + 1² = 1.0
y(0.1) = 1 + 0.1(1.0) = 1.1000
Step 2: x=0.1 → 0.2
f(0.1, 1.1) = 0.1 + 1.21 = 1.31
y(0.2) = 1.1 + 0.1(1.31) = 1.2310
Step 3: x=0.2 → 0.3
f(0.2, 1.231) = 0.2 + 1.515361 = 1.715361
y(0.3) = 1.231 + 0.1(1.715361) = 1.4025
Interactive Solution Trajectory Plot (dy/dx = x + y²) HTML5 Canvas Engine

Python Program (problem_3_euler_method.py)

def euler(x0=0.0, y0=1.0, h=0.1, x_end=0.3):
    steps = int(round((x_end - x0) / h))
    x, y = x0, y0
    for i in range(steps):
        slope = x + y**2
        y = y + h * slope
        x = round(x + h, 4)
    return y

Problem 4: Newton’s Law of Cooling via Euler’s Method

Thermodynamics
Differential Rate Model:
dT/dt = -k(T - Tₐ) = -0.05(T - 20)
Initial condition: T(0) = 90°C, Ambient: Tₐ = 20°C, Step size h = 4 min
Target: Estimate temperature T(8) after 8 minutes.

Two-Step Calculation:

Step 1: t = 0 → 4 min
dT/dt|₀ = -0.05(90 - 20) = -3.5°C/min
T(4) = 90 + 4(-3.5) = 76.00°C
Step 2: t = 4 → 8 min
dT/dt|₁ = -0.05(76 - 20) = -2.8°C/min
T(8) = 76 + 4(-2.8) = 64.80°C
Cooling Curve & Ambient Limit Visualization Asymptote Tₐ = 20°C

Python Program (problem_4_newton_cooling_euler.py)

def newtons_cooling_euler(k=0.05, Ta=20.0, T0=90.0, h=4.0, t_end=8.0):
    t, T = 0.0, T0
    steps = int(round(t_end / h))
    for i in range(steps):
        rate = -k * (T - Ta)
        T += h * rate
        t += h
    return T

Problem 5: Runge–Kutta 2nd-Order Method (RK2)

Predictor-Corrector
Differential Equation:
dy/dx = sin(x - y), y(0) = 1, step size h = 0.1
Target: Compute y(0.3) in 3 successive stages.

Heun's 2nd-Order Formulas

k₁ = h · f(xₙ, yₙ)
k₂ = h · f(xₙ + h, yₙ + k₁)
yₙ₊₁ = yₙ + 0.5 · (k₁ + k₂)
x = 0.0 → 0.1
k₁ = -0.084147
k₂ = -0.072831
y(0.1) = 0.921511
x = 0.1 → 0.2
k₁ = -0.073218
k₂ = -0.060383
y(0.2) = 0.854711
x = 0.2 → 0.3
k₁ = -0.060893
k₂ = -0.047399
y(0.3) = 0.800565 ≈ 0.8006

Python Program (problem_5_rk2_method.py)

import math

def rk2_heun(x0=0.0, y0=1.0, h=0.1, x_end=0.3):
    x, y = x0, y0
    steps = int(round((x_end - x0) / h))
    for i in range(steps):
        k1 = h * math.sin(x - y)
        k2 = h * math.sin((x + h) - (y + k1))
        y += 0.5 * (k1 + k2)
        x = round(x + h, 4)
    return y

Python Program (problem_6_rk2_salt_mixture.py)

import math

def salt_mixture_rk2(h=5.0, t_end=15.0):
    t, y = 0.0, 0.0
    steps = int(round(t_end / h))
    for i in range(steps):
        k1 = h * (12.0 - y / 20.0)
        k2 = h * (12.0 - (y + k1) / 20.0)
        y += 0.5 * (k1 + k2)
        t += h
    return y
